# Codex 执行说明

本仓库作为 `live-poster-codex` Skill 安装到 Codex 后使用。完整的业务规则以 [SKILL.md](SKILL.md) 为唯一准则；同事环境配置见 [COLLEAGUE_GUIDE.md](COLLEAGUE_GUIDE.md)。

## 两个大流程与衔接条件（长期执行）

### 流程一：生成物料

1. 读取本期大纲全文、表格及全部批注；核实期数、日期、星期、19:00开播时间和直播链接；从小助手排期表读取当期三个编号。
2. 按 SKILL.md 第1.0节生成完整四项物料：小助手配置、直播间创建、同步胡亮信息、学院直播预告帖。物料不添加文章安排；后续通知需要的发文安排另外从本期大纲及批注读取。
3. 在当前聊天完整预览；用户确认后，插入飞书物料文档置顶内容之后、前一期之前，并回读检查四项、固定正文和空行。
4. 将已写入的文档链接和核验结果返回当前聊天。用户再次确认飞书版本后，机器人向内容小分队发简短复核请求，真实 @汤爱学（或用户指定复核人）并附本期物料文档链接。
5. 对应复核人明确通过物料后，机器人向 PPT 制作群真实 @胡亮，发送物料第3项下的完整配置正文（至关键词行结束），回读核对正文及机器人发送者。

完成条件：物料已写入并核验、用户确认飞书版本、内容小分队物料复核通过、胡亮配置消息已发送并核验。只生成草稿、只写入文档或只发出复核请求，均不能称为“物料流程完成”。

### 流程二：生成海报

1. 接续流程一，读取 PPT 制作群胡亮本人或“真维斯”代发的本期唯一二维码，核实期数并下载为 `qr_1_{期数}.png`。未取得本期二维码，不制作“有二维码”图，也不把四图交付标为完成。
2. 从已确认的本期物料读取标题、宣传文案、时间、链接及关键词，按当前四图定版生成学院、有二维码、无二维码、横版四张；检查最终 PNG 的文字、断行、留白、时间和二维码。
3. 在当前聊天展示完整四张供用户确认；机器人向内容小分队先发简短海报复核文字，再发四张最终海报。海报复核不重复附已复核的物料文档链接。
4. 用户确认海报且内容小分队明确通过海报复核后，上传固定共享目录下本期文件夹；回读核验四个文件名、数量和路径，再通知 PPT 制作群胡亮/郭凤强。
5. 按正式发布关卡发送226课程群三条消息，再同步预告正文和学院海报到同步群；预告实际发送须为直播当天，日期、星期及19:00一致，正文固定写“今晚7点”。提前准备不得直接提前发布。
6. 建立并核验直播当天北京时间17:00团队群通知；到点核验实际文字和学院海报均由机器人发出；完成本期状态记录与备份。

完成条件：四张最终海报通过确认和复核、共享上传核验完成、对应发布通知完成、团队群到点实际发送核验完成、状态及备份完成。定时任务已加载只表示待执行，不表示本期全部完成。

### 两个流程如何衔接

- “物料复核”与“海报复核”是两次独立复核；物料通过不能替代海报通过，确认不能跨阶段套用。
- 用户要求完整流程时，按流程一→流程二推进；明确确认只触发当前关卡的下一步，遇到二维码或人工复核未到时如实记录等待项，不跳过前置条件。
- 用户明确只做物料时，完成流程一后停止；用户明确只做海报时，先核验本期已确认物料、物料复核及胡亮配置状态，不重复发送已完成的消息。
- 每次报告“下一步”，先回读当前规则与本期执行状态，说明所属大流程、已完成关卡、当前第一个未完成关卡。所有群消息和图片使用 `live-poster-bot --as bot`，逐条回读核验 `sender_type=app` 且 App ID 为 `cli_a94b5144b1381cb3`；显示名不作为唯一判断依据。

## 当前模式

- 每期生成 4 张图：学院、有二维码、无二维码、横版。
- 每期只有 1 张外部二维码，保存为 `qr_1_{期数}.png`，仅用于“有二维码”图。
- 学院图使用直播链接生成二维码；无二维码和横版图没有二维码、没有关键词。
- 所有标题和介绍文案按统一动态布局生成。标题默认最多两行，介绍文案最小字号固定为 96。

## 执行边界

1. 读取大纲时必须读取正文、表格与批注，文章安排以批注为准。
2. 物料生成后先在窗口完整预览，收到明确确认后才写入飞书物料文档。
3. 海报生成后展示完整4张，用户确认且内容小分队海报复核通过后才能上传共享空间；正式发布另按日期和发布关卡执行。
4. 所有群消息、`@` 提醒、图片发送都必须使用 `live-poster-bot` profile 的“直播小助理”机器人身份；云文档、表格、云盘资源操作使用有权限的用户身份。
5. 每条关键群消息发出后，必须读取该消息并确认 `sender.sender_type == "app"` 且 `sender.id == "cli_a94b5144b1381cb3"`。
6. 团队群定时通知只能在直播当天北京时间 17:00 发送。若使用 macOS LaunchAgent，脚本必须以 `Asia/Shanghai` 的 epoch 作最终发送守门。

```text
直播链接：https://...
直播大纲文档：https://...
```

若已完成物料、只需要海报：

```text
调用 live-poster-codex skill，从海报生成步骤开始。
期数：473
二维码已在 PPT 制作群发出。
```

不要把历史 6 图、三张二维码、旧输出命名的内容当成当前规则执行。
