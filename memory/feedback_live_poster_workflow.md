## 2026-07-28 团队群定时任务提前发送复盘与硬修正

- 464期团队群通知要求北京时间 2026-07-28 17:00 发送，但实际在北京时间 2026-07-28 02:09 左右发出，提前约 15 小时。
- 不能只解释原因，必须把防线写进脚本：LaunchAgent/Cron 只是唤醒器，真正是否发送必须由脚本内的北京时间 epoch 守门决定。
- 所有团队群 17:00 定时脚本必须在任何飞书发送动作之前执行：
  - 用 Python `zoneinfo.ZoneInfo("Asia/Shanghai")` 计算目标北京时间 epoch；
  - 如果当前 epoch 早于目标，脚本 sleep 到目标时间再发；
  - 如果当前 epoch 晚于目标 30 分钟以上，脚本停止发送并记录日志，等待用户手动判断；
  - 如果在目标后 30 分钟内，允许发送并继续核验 sender。
- 日志必须记录：本机时间、北京时间、目标北京时间、早到 sleep 秒数、超时退出原因、发送后的 message_id 和 sender 核验结果。
- 禁止只把北京时间手工换算成本机时间写进 `StartCalendarInterval` 就认为完成。任何本机时区/LaunchAgent 触发异常，都不能越过脚本内北京时间守门。
